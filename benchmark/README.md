# 한국어·일본어 예약 통역 벤치마크

2026년 11월, 통합 메모리 48 GiB인 M4 Pro에서 로컬 모델 14개를 비교했습니다.
점원이나 손님이 말을 고치거나 잠시 멈췄을 때 모델이 뒷말을 기다리는지, 번역문에 날짜·인원·이름·예약 조건이 그대로 남는지 확인했습니다.

기본 모델인 Gemma 4 26B-A4B는 번역 시점을 30번 모두 맞혔고, 예약 문장 20개 중 2개에서 뜻을 잘못 옮겼습니다.
같은 문구에서 Gemma 4 12B는 오역이 1개였습니다.
텍스트를 보내 번역문 전체를 받기까지 걸린 시간(p95)은 26B가 904 ms, 12B가 2,763 ms였습니다.
p95는 응답 시간을 짧은 순으로 나열했을 때 95% 지점에 있는 값입니다.

더 작은 Gemma E4B는 같은 판단 문구 30개 중 28개를 맞혔고, 예약 문장 20개 중 3개를 잘못 옮겼습니다.
E4B의 텍스트 번역은 p95가 493 ms였습니다.
합성 음성으로 통역할 때 한국어 발화가 끝나고 브라우저에서 일본어 음성이 재생되기까지 걸린 시간의 중앙값은 E4B가 2.58초, 26B가 2.91초였습니다.
